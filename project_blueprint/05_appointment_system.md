# 5. Smart Appointment System

Normal appointment booking se kaafi better banana hai.

Patient flow:

```
Select Department
       ↓
Select Doctor
       ↓
Select Date
       ↓
Available Slots
       ↓
Book Appointment
```

Features:

- Doctor availability
- Working hours
- Slot generation
- Appointment confirmation
- Rescheduling
- Cancellation
- Waiting list
- Appointment reminders
- Doctor leave management
- Token/queue system
