# 4. Doctor Recommendation System

AI patient ko suitable department suggest karay.

Example:

| Symptoms | Department |
|---|---|
| Skin rash | Dermatology |
| Tooth pain | Dentistry |
| Chest symptoms | Cardiology / Emergency evaluation |
| Eye problems | Ophthalmology |
| Joint pain | Orthopedics |
| Mental-health concerns | Mental Health professional |

Isko doctor diagnosis nahi, "suggested specialty" ke taur par present karna better hai.
